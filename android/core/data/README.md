# 数据实现

状态：已接入构建，实现 Room 快照、待发送、会话请求和草稿记录、HTTP/SSE 业务映射和仓库。schema 2 从 1 增量升级，草稿消费与 outbox 插入共用事务。BackendFactory 组装实时或轮询模式，仓库同事务保存回复/任务/恢复位置，未知受理结果始终保留原身份。

实现业务仓库接口，管理 Room 本地存储、后端数据源、待发送消息和状态对齐。数据库对象与网络响应分别转换成业务实体，页面从仓库读取状态。

依赖 `domain` 与 `network`。按账号隔离缓存，使用稳定请求键重试并按事件序号恢复。服务端数据库位于根目录 `backend/`，本模块不直接连接它，也不负责执行在线 Agent 循环。
