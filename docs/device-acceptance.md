# 阶段 6B2 设备验收清单

状态：部分完成。2026-10-05 在本项目独立的 `CharacterAgent_API35` 无窗口模拟器（Android 15 / API 35 / x86_64 / 1080×2340）完成 13 个设备/主机检查点，含 12 项正常结束的 JUnit 和 1 项主机验收的前台强杀。新增证据见 [6B2C 报告](stage-reports/06b2c-recovery-and-upgrade.md)，首轮六组检查见 [6B2B 报告](stage-reports/06b2b-device-debugging.md)；完整设备验收仍未完成。

使用开发版 APK 和隔离的模拟后端，连接方法见 [Android 说明](../android/README.md)。记录设备/系统、应用提交、执行日期和实际结果；记录中不包含连接凭证、模型密钥或带凭证的截图。

| 场景 | 验收动作与通过条件 | 结果 |
| --- | --- | --- |
| 首次连接与重启 | 保存开发连接，关闭重开应用；能读取加密配置并访问原身份数据 | 通过：真实设置入口、Keystore 加密及跨进程读取 |
| 本地草稿 | 输入中文、空格、换行和表情，等“已保存在此设备”；切会话、旋转、切后台后仍准确恢复 | 部分通过：自动化输入、横竖屏、生命周期退后台/恢复、返回再进入；同一身份多会话切换待验 |
| 系统终止 | 草稿保存完成后强制停止应用，再打开；草稿和原消息恢复，未自动发送 | 通过本项强制停止场景：核对前台 Activity 和存活 PID 后、测试退出前强杀；完整草稿恢复，服务端消息集合未增加；不代表低内存回收或断电 |
| 编辑清空 | 删除全部输入，保存完成后终止再打开；草稿保持空白 | 通过：清空落库，再启动为空 |
| 发送交接 | 发送后立刻继续输入下一条并保存，再终止重开；原发送保持原请求身份，新草稿独立存在 | 通过：新草稿独立恢复；离线 outbox 使用原 ID/键重试 |
| 模式与身份 | 草稿保存期间切实时/兼容模式；再切另一开发身份并返回，内容不串用 | 部分通过：切两种模式、兼容模式实际回复、A/B 草稿隔离；保存进行中的切换待验 |
| 网络恢复 | 实际切断设备到服务的通路，再恢复，验证错误提示、缓存可读、原请求重试和事件续接；记录具体断网方式。USB 端口转发下只切飞行模式不能算已断开服务连接 | 部分通过：关闭隔离服务并确认端口关闭，缓存可读、失败保留和原请求重试通过；回复进行中的设备断流续接待验 |
| 停止与下一轮 | 回复期间停止，再发送下一条；旧连接不拖住新回复，已保存的笔记不撤销或重复创建 | 通过：真实笔记提交后暂停部分输出，点击停止后任务为 cancelled；笔记仅一份，下一新任务完成，新草稿保留 |
| 输入法与显示 | 多行键盘、表情、光标编辑、深浅色和返回操作正常；保存提示不遮挡发送入口 | 部分通过：深浅色、状态栏、软键盘显示、多行和发送入口截图；中文候选与光标手动编辑待验 |
| 覆盖安装升级 | 先在 schema 1 版本准备消息及未确认待发送项，再覆盖安装新版；数据和请求身份保留，能保存新草稿 | 通过：历史 APK 经真实界面准备数据，直接覆盖到 schema 2；旧表逐行相同，加密连接可用，原 ID/键重放 200，新草稿重开恢复；限本机调试签名和该历史版本 |

若某项失败，记录可复现步骤和脱敏错误，修复后只重测相关场景及必要回归。所有项目明确验收后，才把阶段 6B2 整体标为完成。
