# Android 通信边界与恢复规则

阶段 6B1 已实现；核心选择记录在 [D22–D24](decisions.md)。

## 接口和替换位置

```text
Compose 页面 → CharacterRepository → OfflineRepository / Room
                                         ↓
                               ReliableBackend + RunMonitor
                                         ↓
                                    BackendAdapter
                                   ↙              ↘
                      HttpBackend + HTTP/SSE    内存模拟（测试）
```

BackendAdapter 的操作是列角色、创建会话、发起/查询/取消任务、读取笔记及订阅 RunEvent，不暴露 HTTP 方法、URL、JSON、Room 或主题。适配器显式声明 supportsEvents，并提供 close。HttpRequests/HttpEvents 是 HTTP 实现内部边界，不作为所有协议的共同接口。

运行时设置可以选择默认实时连接或兼容轮询。默认尝试 SSE，事件通路无法恢复时回退查询；兼容模式直接查询。模式保存在本机，同一地址和凭证继续使用原缓存。不同地址或凭证仍然隔离。BackendFactory 集中组装，关闭旧连接后再使用新适配器。

增加新协议需要：实现 BackendAdapter，将协议错误/数据/事件转换为领域类型，声明能力，接入工厂，然后运行 AdapterContract 与故障测试。服务端必须实际支持该协议和相同的去重约定。当前没有 WebSocket/gRPC，也没有运行时下载插件；MCP 是未来工具接入边界，不是聊天流的别名。

## 已实现策略

| 情况 | 当前行为 |
| --- | --- |
| 断网、超时、429、可恢复服务错误 | 安全操作最多 3 次尝试，共 25 秒；指数退避和随机抖动 |
| Retry-After | 支持秒数与 HTTP 日期；不会缩短服务端等待时间，超预算交回失败 |
| 凭证、权限、冲突、输入错误 | 转为安全错误，不无限重试，不显示原始响应或凭证 |
| 已受理但响应丢失 | 原请求身份重试；服务端去重；Room 保留结果不明状态 |
| 收到重复或旧事件 | 忽略，不追加相同正文，不让旧状态覆盖终态 |
| 事件缺号、未知事件类型 | 读取完整任务快照，确认覆盖缺失序号后再继续 |
| 断流或不完整帧 | 不当作完成；从已提交位置重连；最多 3 次流连接后回退查询 |
| 事件格式不兼容 | 尝试用完整快照恢复并进入查询模式；快照也不可用则报错停止 |
| 认证失败 | 立即停止该观察，不通过另一个接口绕开认证 |
| 查询重试耗尽 | 保留缓存和任务，停止自动观察；用户点“重新连接”或重新进入前台可恢复 |
| 切后台/离开页面 | 取消观察连接与等待，服务端任务继续；前台重新核对 |
| 用户点停止 | 独立发送幂等取消请求，不等待发送锁；已保存产物不撤销 |
| 切换连接/退出 | 取消旧会话，关闭 HTTP 客户端，阻止旧界面状态覆盖新连接 |

每次事件提交在同一事务写入输入/回复消息、任务状态及 last_event_sequence；游标复用已有任务字段，没有 schema 变更。普通 HTTP 响应最多 4 MiB，单个 SSE 帧最多 512 KiB，队列最多 16 帧；超过限制转为协议错误。

SSE 连接空闲 35 秒会失败并恢复，服务端每 15 秒发送心跳；这不是整个 AI 任务的执行时限。EOF 不构成终态，只有明确任务状态才决定完成、失败或取消。底层不开启重定向和自动连接重试，避免凭证改变发送目标与重试叠加。

## 验证和范围

运行 `backend/.venv/Scripts/python.exe backend/scripts/check_android.py`。脚本创建隔离模拟后端，执行纯 Kotlin 可靠性策略、真实套接字、Room 和真实 Python API/SSE 测试；凭证不进入参数和日志，结束清理临时数据。

共用 AdapterContract 对内存模拟、HTTP 实时模式、HTTP 轮询模式验证会话/消息重试、同键不同内容冲突、完整读取和终态取消。额外故障测试覆盖断流重连、缺号/重复、错误帧、认证失败、等待取消、限流、结果不明与数据库重开；真实 SSE 也直接写入 Room 并保存笔记。

模拟适配器是测试用替身；产品首次加载和发送仍需要后端。没有真实模型调用或真实 MCP 验证，也没有真机/模拟器的断网、切后台、Keystore 和 UI 验收。自动恢复仅限前台观察，不包含 WorkManager、后台自动发送、跨设备推送、正式认证、监控告警、熔断或服务高可用。草稿持久化留在阶段 6B2。
