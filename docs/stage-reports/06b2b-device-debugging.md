## 发现的问题与修复

1. **应用显示问题**：深色页面在系统浅色模式下仍显示深色状态栏图标。修复为状态栏图标跟随应用主题；保留 Android 对导航栏和输入法区域的管理，设备断言核验主题切换后的标志，并查看截图。
2. **测试构建兼容性**：全局改 `testBuildType` 导致原有 `:app:testDebugUnitTest` 入口不可用。现在只在设备脚本传入 `-PdeviceChecks=true` 时选择测试构建，普通构建保留原入口；完整 61 项回归重新通过。
3. **Windows 测试服务退出**：虚拟环境 Python 启动器下还有实际解释器子进程，仅停启动器不够；启动外部清理程序又可能让短回复在强停前完成。新增开发依赖 psutil，终止本轮父子进程对象并等待退出；实际中断、重启与停服端口检查通过。
4. **测试记录准确性**：清理失败原先可能被忽略，现在单列清理结果并将整轮判为失败。草稿空值按可编辑内容判断，不把占位文字当正文；原请求核对使用协议中的 `client_message_id`，不误用服务端另行生成的消息 ID。

初次复用的模拟器曾中途退出，不能算应用通过。已保留该次环境中断和清理失败记录，随后改用独立无窗口 AVD。原模拟器再次上线后，已只读确认专用测试包不存在；本次独立 AVD 验收结束后关闭。脚本调试期间的失败记录均保留；最终成功轮次不会覆盖它们。
