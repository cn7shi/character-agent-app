# 阶段 4A：兼容模型接口与凭证保护

日期：2026 年 10 月 5 日。用户选择“先支持 OpenAI 兼容接口，稍后选服务”，并要求通过 Git 忽略等方式保护密钥。本阶段完成适配和保护，不声称已完成真实外部模型联调。

## 交付

- `TextModel` 新增 OpenAI 兼容的 Chat Completions 文本流适配；模拟模式保留并作为默认。
- 本机 JSON 配置与环境变量入口；无凭证示例可提交，本机配置、日志、密钥及运行数据忽略提交。
- 支持模型名称、API 基址、超时、输出上限参数选择；HTTPS 外部连接、禁止 URL 携带凭证、不自动跳转或重试。
- 解析 UTF-8 分片与 SSE，区分完整回复、断流、截断、鉴权失败、限流和不支持的工具调用。
- 取消关闭供应商连接；上下文保留完整成功轮次，并增加字符预算。
- 配置校验不回显原值，密钥对象默认隐藏，日志对当前密钥脱敏，供应商原始错误不写入业务记录。
- 提交前检查暂存区、推送前检查可达历史。当前工作区启用 Git 钩子，新克隆可按文档启用。
- 更新运行说明、设计原因、错误协议与 OpenAPI；本机空白配置保持模拟模式。

## 验证

`backend/run-tests.ps1`：46 项测试通过。包含原有行为回归，以及协议帧、中文分片、限流/鉴权/超时、错误信息隐藏、配置校验、取消释放连接、上下文完整性和 Git 拦截。

其中 3 项通过真实回环 HTTP 服务验证：配置加载到模型调用、结果保存与幂等重试、取消时实际 TCP 关闭、供应商 HTTP 失败和提前 EOF。供应商是测试程序，不是真实 AI。

Git 检查使用临时仓库与合成假密钥，验证：强制添加被忽略文件会拦截；只清理工作区仍能检出暂存内容；密钥进入某次提交后，即便最新提交删除了它，推送检查仍会拦截。检查不打印匹配值。

`backend/scripts/smoke_server.py`：模拟模型下原有真实 HTTP/SSE 断流恢复、取消和进程重启验证通过。测试固定自己的模拟配置，不读取实际模型凭证或调用付费服务。

## 当前限制与下一步

未使用真实模型密钥，未验证特定供应商。当前只支持兼容纯文本协议，Responses、多模态、工具调用、Agent、MCP 和 Android 尚未接入。日志脱敏和模式扫描用于减少误泄露，不能代替生产密钥管理或所有形式的安全审计。

服务确定后，在本机填写配置，再进入阶段 4B 验证真实流式回复、错误、取消及供应商参数差异。
