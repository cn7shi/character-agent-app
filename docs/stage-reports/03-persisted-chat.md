# 阶段 3：持久化模拟聊天

日期：2026 年 10 月 5 日。交付一个可以从提交消息走到保存回复的后端闭环，供后续真实模型与 Android 复用。

## 实际交付

- 增加消息、任务和事件的数据库迁移；已有角色与会话数据保留。
- 原子受理用户消息、回复占位、任务、去重记录与第一个事件。
- 模拟模型通过 `TextModel` 接口接入，响应字段与文本均明确标记模拟。
- 后台读取已保存的排队任务，生成不依赖客户端保持连接。
- 提供任务查询、取消、SSE 订阅及按事件序号恢复。更新事件包含完整消息快照。
- 消息历史按会话序号分页，取消与失败保留部分回复。
- 数据目录只允许一个开发执行器。重启将遗留任务标记为 `RUN_INTERRUPTED`，不自动再次调用模型。
- 导出 9 个路径、10 项操作的 OpenAPI，更新协议样例与运行说明。
- 在用户指定的私有 GitHub 仓库 `cn7shi/character-agent-app` 保存阶段源码和文档；本机目录继续使用 `E:\MyProject\Company`。

## 验证结果

`backend/run-tests.ps1`：27 项行为测试全部通过。保留原有 16 项测试，新增 11 项覆盖并发去重、事务回滚、跨用户访问、历史分页、上下文范围、取消、错误屏蔽、超时、服务关闭、旧数据库升级、多批事件回放与单执行器恢复。

`backend/scripts/smoke_server.py`：真实本机 HTTP/SSE 通过，实际断开正在生成的事件流并恢复读取；验证取消、进程停止再启动、部分回复保留、旧任务重试不重复生成、历史记录与事件仍可读。测试结束后进程已关闭，临时数据库已清理。

接口导出与 JSON 示例检查通过。以上验证使用明确的模拟模型，没有调用真实模型、MCP 或 Android 设备。

## 已知边界

- 仅供本机开发：随机开发身份不是正式账号系统，没有生产配额或多进程任务队列。
- 模型读取时限 30 秒，输出上限 16000 字符，最多并行 8 个任务；上下文仅取本会话最近 20 条已完成消息，未实现长期记忆。
- 服务崩溃时恢复状态，不能恢复原模型流；用户可以明确发送新的任务。
- 事件保留完整快照，尚无压缩和过期裁剪，不适合无界增长。
- 当前 TestClient 的 httpx 兼容接口有弃用提示，不影响测试；后续统一调整测试依赖。
- Android 仍是目录与职责预留，Room、主题页面、真实模型、Agent 工具及 MCP 尚未实现。
