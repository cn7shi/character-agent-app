# 阶段 6B1：网络可靠性与可拔插边界

日期：2026-10-05。对应用户要求：补全网络可靠性和可拔插机制，继续使用固定回复，不等待 AI 配置。

## 交付

- 新增纯 Kotlin BackendAdapter / RunEvent / BackendFailure，声明事件能力与关闭生命周期。HTTP 机制与业务接口分开，替换适配器不需要页面理解协议。
- 实时 HTTP/SSE 和兼容 HTTP 查询两种运行时模式，设置持久化；同地址与凭证的模式切换保留缓存。内存模拟实现参与共同契约测试，不作为无后端产品模式。
- 安全读取与声明幂等的创建/取消共享有限重试：最多 3 次、25 秒总时限、指数退避与抖动，尊重 Retry-After，不向界面泄漏原始响应或凭证。
- SSE 按已落库位置恢复；正文、任务及序号共用 Room 事务。重复事件忽略，缺号/未知事件核对完整快照；断流不视为完成，有限重连后回退查询。
- 观察取消会关闭套接字；后台/前台切换接入协程取消和恢复，切连接释放旧客户端并拦截旧界面更新。用户停止不受提交锁阻塞，且不会撤销已保存工具产物。
- 补强结果不明的边界：坏响应、超时、取消/进程退出后始终保留原请求身份，之后的拒绝不被误当成首次未受理。
- [D22–D24](../decisions.md) 记录问题、原因、选择、代价及复评条件；[通信说明](../network-reliability.md) 记录实际参数与扩展步骤。

## 本阶段边界与下一步

这次修改客户端通信和联调脚本，后端业务/API 保持现有实现。模拟回复与规则笔记是真实网络联调的内容，不代表真实模型或 MCP 已验证。没有 WebSocket/gRPC、正式登录、后台自动发送、生产监控、熔断或高可用部署。

没有连接手机或配置 Android 模拟器；构建、Robolectric 与本机 TCP 测试不能证明真机切后台、系统断网、Keystore、输入法和界面行为已经通过。下一步 6B2 补持久草稿/迁移，再做设备验收；之后继续原型主题。
