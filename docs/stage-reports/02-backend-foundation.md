# 阶段 2 后端与数据基础

日期：2026 年 10 月 5 日。本阶段已完成可运行后端基础，验证服务已停止，没有留在后台运行。

## 实现结果

- 配置独立 Python 环境与固定依赖，提供本机启动、测试和接口导出入口。
- 实现开发用户隔离、两个示例角色、角色详情与分页、独立会话创建与分页、空消息查询。
- 用本项目独立 SQLite 保存用户、角色、人设版本、会话和请求去重记录；迁移具有版本与校验记录。
- 会话创建在同一事务内保存资源和去重记录，同键重试返回原会话，同键不同内容返回冲突。
- 请求统一校验，私有资源按用户检查归属，公开角色资料不暴露私有提示词。
- 导出当前实际实现的 OpenAPI，共 5 个路径、6 项操作。

## 验证结果

16 项行为测试全部通过，覆盖身份拒绝、回环限制、用户隔离、同角色多会话、分页范围、标题校验、并发去重、事务回滚、外键约束、迁移校验及应用重启保留。

其中 8 个同时到达的相同创建请求仅生成 1 个会话和 1 条请求记录；两份并发的不同内容使用同一请求键时，一份创建成功，另一份返回冲突。

另外启动真实 Uvicorn 子进程，通过本机 HTTP 验证匿名拒绝、角色查询、会话创建和跨用户访问拒绝。停止进程后使用同一数据库重新启动，确认会话仍存在，原请求重试返回同一记录。随后停止子进程并清理临时数据。

最终检查确认 16 个已安装依赖包兼容，OpenAPI 导出与当前代码一致，23 份文档中的 35 个本地链接有效。中断验证留下的临时目录也已清理。

当前验证环境：Windows、Python 3.14.6。TestClient 的 httpx 兼容接口有第三方弃用提示，测试仍通过；后续统一更新测试客户端。Windows 受限沙箱阻止异步运行时的回环连接，因此测试在获准的本机执行环境运行。

## 编写原因与修正

新增 [设计决策记录](../decisions.md)，说明事务、人设版本、游标范围、开发身份和连接管理的原因、代价及调整条件。根目录 `AGENTS.md` 固定后续持续记录的协作约定。

验证过程中发现测试自身的 SQLite 连接未显式关闭，导致 Windows 无法清理临时数据库；已改用统一连接管理入口，重新验证全部通过。应用仓库本身从一开始即显式关闭连接。

## 当前限制

- 仅供本机开发，正式账号注册登录和对外部署尚未实现。
- 消息查询只针对已授权空会话返回空列表；消息写入、聊天生成、任务和事件流在下一阶段实现。
- 未调用真实模型，没有 Agent 工具、MCP、Room 或 Android 页面。
- 原型项目及其数据库未修改。
